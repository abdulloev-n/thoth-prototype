# Thoth: кликабельный прототип

Один файл `index.html`, без сборки и без зависимостей. Открывается двойным кликом или через GitHub Pages.

Данные демо живут в памяти страницы: после перезагрузки всё возвращается к исходному состоянию.
Слева на широком экране есть карта из 13 экранов, по ней можно прыгать напрямую.

GitHub Pages: Settings → Pages → Source: Deploy from a branch → main / root.
